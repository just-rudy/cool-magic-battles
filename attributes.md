# Памятка по игровым атрибутам

## Player/Игрок

* **Health points/Health/HP/Очки здоровья/Здоровье/ОЗ**  
  Количество урона, которое игрок может выдержать, прежде чем умереть. Когда очки здоровья игрока достигают нуля, он умирает и возрождается с полным здоровьем (по умолчанию 20).

* **Echo points/Echo/EP/Очки Эхо/Эхо/ОЭ**  
  Накапливаемые очки, которые игрок получает в результате розыгрыша карт. Могут быть потрачены на покупку новых карт из колоды рынка. Каждый ход сбрасываются. В начале игры "собственное" количество эхо равно 0, но может быть увеличено с помощью эффектов карт.

* **Memento of Mortaliy/Memento/Memo/MM/Памятка о бренности бытия/Памятка/ПББ**
  игровой элемент, выполняющий роль индикатора смертей в игре. В начале каждой партии определяется общее количество памяток (по умолчанию количество игроков * 4). Каждый раз, когда игрок умирает, он получает памятку. Когда все памятки расходованы, игра заканчивается. Каждая памятка отнимает у игрока определенное количество очков крутости.

* **Cool Points/CP/Очки крутости/ОК**  
  очки, которые игрок получает вместе с купленными картами. В конце игры очки крутости карт суммируются со штрафами за памятки о бренности бытия и определяют победителя. Чем больше очков крутости, тем круче игрок. В случае ничьей по очкам крутости, побеждает игрок с наибольшим количеством купленных карт. Если и по количеству купленных карт ничья, то побеждает игрок с наибольшим количеством карт случайно выбранного типа. Если и по этому показателю ничья, то победитель определяется путем сражения между игроками (например, камень-ножницы-бумага или дуэль на мечах).

## Card/Карта
* **Action/Effect/Действие/Эффект**(он же тип карты)  
  действие, которое выполняется при розыгрыше карты. Может быть атакой, защитой, добором карт, увеличением руки или базового количество эхо игрока.
* **Power/Сила**   
  числовое значение, определяющее силу действия карты (количество наносимого урона, количество добираемых карт и т.д.)
* **Cost/Цена**  
  количество очков эхо, необходимое для покупки карты из колоды рынка
* **Cool points/Очки крутости**  
  количество очков крутости, которая карта приносит игроку
